# Gestión de Memoria y Punteros en C++

## Descripción

Este repositorio contiene ejercicios prácticos desarrollados en C++20 para trabajar con punteros y gestión dinámica de memoria.

## Ejercicios

### Ejercicio 1. ListaDeObjetos
Implementación de una lista de objetos mediante un array dinámico, con métodos para agregar y extraer elementos.

### Ejercicio 2. ListaDePunteros
Implementación de una lista que almacena punteros a objetos, permitiendo agregar y extraer elementos.

### Ejercicio 3. Cadena
Creación de una clase que almacena una cadena de caracteres mediante memoria dinámica, utilizando un constructor y un destructor para gestionar la memoria.

### Ejercicio 4. Cola
Implementación de una cola mediante un array dinámico, con operaciones para agregar y quitar elementos siguiendo el principio FIFO (First In, First Out).

## Tecnologías utilizadas

- C++20
- CLion
- CMake
- Git y GitHub

## Ejecución

Cada ejercicio se encuentra en un proyecto independiente de CLion.

Para ejecutar un ejercicio:

1. Abre su carpeta en CLion.
2. Comprueba la configuración de CMake.
3. Ejecuta el archivo `main.cpp`.

## Objetivo

Practicar el uso de punteros, arrays dinámicos, constructores, destructores y liberación de memoria en C++.
